Security

Report suspected security issues privately so they can be reviewed before public disclosure.

Contact

security@bassthermal.com

Include

Name the affected product and version, platform, reproduction steps, possible impact, and any logs or screenshots that can be shared safely.

Do not send

Do not email passwords, authentication tokens, payment details, private working documents, or other sensitive personal information.

Disclosure

Please allow time for the report to be reviewed before publishing technical details. BassThermal does not currently operate a paid bug-bounty program.
