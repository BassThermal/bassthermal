Common questions

Frequently asked questions.

Does the public directory publish my book inventory?

No. The planned directory is for optional business profile fields only. Catalog records, transactions, customers, and inventory must never be published through that feature.

Is directory participation automatic?

No. The attached desktop concept is off by default, previews the chosen public information, and exports only a draft request. A live system would still need explicit consent and verification.

How much does ISBN Manager cost?

Final pricing for the proposed website and expanded bookstore offering has not been set here. The pricing page is a structural concept and contains no live checkout.

What happens to people who already bought ISBN Manager?

Preserving existing customers’ purchased functionality is a product requirement. Exact migration, upgrade eligibility, and license rules must be written and verified before commercial launch.

Will the app work during an internet outage?

Offline continuity for paid features is a design requirement. The eventual implementation will need locally verifiable entitlements and carefully defined grace/expiry rules. This website concept does not implement or certify that behavior.

Does Stripe process the bookstore’s customer payments?

No. Future Stripe integration discussed for this product is for purchasing or managing ISBN Manager licenses and subscriptions. It is not the payment system for a bookstore’s POS customers.

Is ISBN Manager available for macOS?

The product direction represented in this concept is a Windows desktop app. Do not assume a macOS release from this page.

How do I get support or request a feature?

You can contact BassThermal at info@bassthermal.com and include the app version, a description of the issue, and steps to reproduce it. See the official BassThermal support page for additional guidance.

Still need a hand?

Direct support is available through BassThermal. Include exact symptoms and the app version.
