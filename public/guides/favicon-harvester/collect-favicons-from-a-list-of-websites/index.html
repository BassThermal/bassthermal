Favicon Harvester guide

Collect Favicons from a List of Websites

Prepare clean domain input, scan for available site icons, review the candidates, and save a collection that is actually usable.

Published July 28, 2026 · Windows

Favicons are not always stored in the same location or format. A useful harvesting workflow checks more than one candidate, then lets you review the results instead of blindly accepting the first file found.

1. Prepare the website list

Use one domain or URL per line. Remove duplicates and obvious non-web text before scanning so the result set stays easy to review.

2. Run the scan

Start with the cleaned list and let Favicon Harvester inspect the sites for available favicon and site-icon assets. Some domains may expose several candidates while others may expose none.

3. Review quality and identity

Check that each discovered image actually represents the intended site. Prefer a clear square asset with enough resolution for the destination where you plan to use it.

  • Reject generic browser or hosting icons.
  • Watch for stale branding.
  • Keep transparent and non-transparent variants separate when useful.

4. Save an organized collection

Export or save the accepted icons into a dedicated folder. Use stable names tied to the domain so the collection remains understandable after the scan is finished.

Common mistakes

  • Pasting mixed prose instead of a clean URL list.
  • Assuming the first candidate is always the official icon.
  • Keeping tiny or blurry assets without review.
  • Saving files without domain-based names.
