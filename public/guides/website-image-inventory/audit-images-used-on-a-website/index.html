Website Image Inventory guide

Create an Image Inventory for a Redesign or Migration

Scan public pages, see where images are referenced, and turn URLs, dimensions, hosts, file types, sizes, and repeat counts into a practical migration or cleanup worksheet.

Published July 28, 2026 · Updated July 29, 2026 · Windows

A website image audit is more useful than a folder full of downloads. The real questions are which images the public pages reference, where those assets are hosted, how large they are, how often they repeat, and which ones deserve attention before a redesign or migration.

Choose a starting URL that matches the scope

Use the public homepage for a broad site inventory or begin from a specific section when the project covers only part of the site. Record the starting URL and scan date so the exported inventory still makes sense weeks later.

Scan the public pages

Let Website Image Inventory crawl from the chosen public URL and collect the image references and available metadata it can reach. Larger sites can take longer, and scan limits or inaccessible pages can affect the final scope. Private, authenticated, or blocked content should not be assumed to be included.

Understand the inventory fields

Review the fields that help explain each discovered asset, such as the image URL, source page, host or domain, dimensions, file type, file size, and repeated-reference count where available. These details are more useful than filenames alone because the same asset may appear on many pages or be served through an external host.

Find the assets that deserve action

Use the inventory to identify unusually large files, repeated interface graphics, external hosts, old formats, and images that appear across many pages. Repeated references do not automatically prove that two different URLs contain identical bytes, so keep that distinction clear during cleanup.

  • Separate content photography from interface and branding assets.
  • Flag large dimensions or file sizes for optimization review.
  • Note externally hosted images that may need permission or migration planning.
  • Use repeat counts to prioritize assets with broad site impact.

Export for the redesign or migration team

Export the reviewed inventory to CSV or JSON for sorting, estimation, migration mapping, or handoff. Keep the scan date, starting URL, and any known crawl limits with the file so nobody mistakes the inventory for a complete record of private or unreachable content.

What this inventory does not prove

The scan organizes image references and metadata from reachable public pages. It does not automatically decide copyright status, accessibility quality, brand relevance, or whether two visually similar files are safe to consolidate. Those remain human review decisions.
