ISBN Manager

Look up ISBN metadata, maintain book inventory, and generate barcode labels.

windows
overview
ISBN Manager supports Windows book-catalog workflows: look up ISBN metadata, create and clean book inventory records, generate barcode labels, organize fields, and export book records. It is aimed at bookshops, libraries, collectors, and small inventory projects that need repeatable catalog cleanup.
workflow
  1. Enter, paste, import, or scan ISBNs.
  2. Review fetched metadata and clean inventory fields.
  3. Generate barcode labels and export organized records.
use cases
  • clean up used book inventory
  • look up book metadata from ISBNs
  • prepare barcode labels for book records
  • export organized catalog data
