Website Image Inventory

Scan reachable public pages and organize their discovered image references and metadata.

Windows

what it does

Website Image Inventory crawls from a public starting URL and creates a reviewable inventory of discovered image references. The result is designed for analysis and handoff, not merely as a folder of downloaded files.

how it works

  1. Choose a starting URL and scan scope that match the website section being reviewed.
  2. Collect reachable image references and available source-page, host, dimension, format, size, and repeat information.
  3. Review the findings and export an inventory for cleanup, redesign, migration, estimation, or research.

useful for

  • website redesign and migration planning
  • finding large or widely repeated image references
  • reviewing external image hosts and older file formats
  • creating a structured worksheet for web teams and site owners

requirements + limits

  • The scan covers reachable public pages within the selected scope; private, authenticated, blocked, or unreachable content is not assumed to be included.
  • Repeated references do not automatically prove that different URLs contain identical image bytes.
  • The inventory does not decide copyright status, accessibility quality, brand relevance, or whether an asset is safe to consolidate.

Does the scan include private or authenticated pages?
